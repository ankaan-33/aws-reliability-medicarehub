Resilience built in

  • Auto Scaling group across two AZs replaces failed instances automatically
  • ALB health checks route traffic only to healthy instances
  • Multi-AZ RDS MySQL with a synchronous standby
  • Shared Amazon EFS storage at /uploads/, the same on every instance
  • Route 53 failover to a static maintenance page if the whole stack is unhealthy

Shared storage check

Every instance writes a line to /uploads/instances.log on EFS when it boots. Terminate an instance, and its replacement's line appears in the same file.
